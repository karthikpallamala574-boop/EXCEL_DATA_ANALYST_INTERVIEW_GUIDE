# 📊 Excel for Data Analyst — Complete Interview Training Guide

A structured, level-by-level Excel guide built for **Data Analyst interview preparation** — from absolute basics to advanced tools like Power Query and VBA.

Every concept in this guide follows the same format: **Definition → Simple Explanation → Real Example → Interview Answer → Follow-up Questions → Common Mistakes → Related Concepts** — so it's not just theory, it's built to help you actually speak the answer confidently in an interview.

---

## 🎯 Who This Is For

- Freshers preparing for their first **Data Analyst / Business Analyst** interview
- Anyone who knows Excel functions but struggles to **explain them out loud** in an interview
- Learners who want a **structured revision path**, not scattered YouTube notes

---

## ✅ How to Use This Guide

1. Go level by level in order — later levels build on earlier ones.
2. For each concept, read the definition and explanation, then try the example in Excel yourself.
3. Practice the **Interview Answer** out loud in your own words.
4. Attempt the **Follow-up Questions** before checking the given answer.
5. Use the **Quick Revision** table at the end of each level as a fast recap before an interview.
